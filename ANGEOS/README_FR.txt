========================================
                 ANGEOS
           LIVE USB SYSTEM
========================================

DESCRIPTION
ANGEOS est une distribution Linux
personnalisée basée sur Debian.

CARACTERISTIQUES
- Demarrage depuis une cle USB
- Bureau XFCE personnalise
- Interface noire et blanche
- Terminal integre
- Outils reseau
- Outils Python
- Mode Live sans persistance configuree

CONSTRUCTION
Le projet doit etre compile dans
un environnement Debian compatible.

Le fichier ISO sera genere dans
le dossier principal du projet.

ATTENTION
Le mode Live ne garantit pas une
absence absolue de traces sur le PC.
